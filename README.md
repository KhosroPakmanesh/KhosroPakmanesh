## 👋 About me

I'm a senior software engineer with **over 15 years of experience** designing, building, integrating, and modernizing business-critical software. My strongest technical foundation is in **C#/.NET and Microsoft Azure**, but I work across backend, frontend, cloud, and integration technologies according to the problem at hand.

I believe software engineering is less about allegiance to a particular framework and more about **understanding the business problem, managing complexity, making sound trade-offs, and delivering software that can evolve**. I enjoy taking ownership across the development lifecycle, from requirements and domain understanding to architecture, implementation, testing, deployment, and improvement.

I've worked on enterprise and SaaS applications, APIs, ERP and third-party integrations, business workflows, cloud services, data migration and conversion, and user-facing applications. I particularly enjoy making existing systems easier to understand, change, test, and extend through pragmatic architecture and incremental modernization.

I'm interested in how **AI-assisted and agentic coding workflows** can improve software delivery without compromising engineering judgment, verification, security, or maintainability. Separately, I'm **developing my AI engineering skills**, starting with hands-on experiments using **Microsoft Agent Framework in C#/.NET**, and expanding my learning toward the Python agent ecosystem.

## 🧭 How I approach engineering

> **Requirements → Domain Understanding → Architecture → Implementation → Testing → Evolution**

- **Business first:** Understand the real problem and constraints before selecting technology.
- **Evolvable design:** Favor clear boundaries, suitable patterns, and designs that accommodate change.
- **Pragmatic modernization:** Refactor incrementally when possible instead of rewriting without a clear reason.
- **Reliable delivery:** Invest in automated tests, integration testing, observable behavior, and maintainable code.
- **Appropriate cloud solutions:** Balance scalability, resilience, operational complexity, and cost.
- **Adaptability:** Apply strong engineering fundamentals across languages, frameworks, and new tools.
- **Collaboration:** Share knowledge through code reviews, mentoring, and constructive technical discussions.
